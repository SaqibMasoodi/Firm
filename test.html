How the mask works

A sampling window surrounds the five stars, and a traced boundary isolates the notification badge from the nearby fingers and phone. An SVG filter converts dark pixels inside those regions into mask opacity. The colored layer appears only through that mask, so it inherits the original silhouettes, edge detail and light cutouts. “Show mask” displays the isolated pixels in white on black; “Apply accent” lets you compare with the grayscale source.

This proof of concept uses hand-positioned windows and a brightness threshold, so it works for dark, isolated objects. It cannot infer objects or distinguish overlapping dark regions. More complex images need an individually prepared object mask, aligned to each source image. Keep image and mask in the same coordinate system; a shared --accent variable can then drive every service image.
